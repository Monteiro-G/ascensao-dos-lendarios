# Ascensão dos Lendários

Álbum digital interativo de animes e filmes desenvolvido como projeto web, com experiência inspirada em álbuns físicos de figurinhas.

## Sobre o projeto

Ascensão dos Lendários é uma experiência frontend estática que reúne uma coleção de figurinhas em um álbum navegável e animado. O progresso da coleção é mantido no próprio navegador.

## Funcionalidades

- Álbum digital interativo
- Páginas animadas
- Deck de figurinhas
- Drag & Drop
- Colagem de figurinhas com animações
- Visualização ampliada
- Status das figurinhas
- Persistência da coleção no navegador
- Botão para devolver todas as figurinhas ao Deck

## Tecnologias

- HTML5
- CSS3
- JavaScript
- PageFlip
- LocalStorage

## Como executar localmente

Como o projeto carrega o catálogo por meio de `fetch()`, execute-o usando um servidor web local. Uma opção simples é abrir a pasta no Visual Studio Code e usar a extensão Live Server. Depois, acesse o endereço fornecido pela extensão no navegador.
